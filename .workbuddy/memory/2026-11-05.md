# 2026-11-05 工作日志

## R2 注册登录与鉴权
- 新增 `src/server/auth.ts`：scrypt + 16 字节盐（`hashPassword` 返回 `salt:hash`），`timingSafeEqual` 比对，HMAC-SHA256 签名 token（`userId.sig`），`getCurrentUser`/`requireUser`/`requireAdmin` 守卫，`SESSION_SECRET` 缺失模块加载即 throw。
- 新增三个 Route Handler：`register`（用户名 4-20/密码≥6/昵称非空/重名 409/`FIRST_USER_IS_ADMIN=1` 时首个账号 admin）、`login`（统一「用户名或密码错误」401）、`logout`（删 cookie）。
- 页面 `/login`、`/signup`（客户端表单，`window.location` 读 `?next=` 跳转，`startsWith('/')` 防开放重定向）。
- `Navbar`（async 服务端组件，内部 `getCurrentUser` 读 cookie）+ `LogoutButton`（客户端叶子）；`layout.tsx` 用 `<Suspense>` 包裹 Navbar。
- **关键坑**：`cacheComponents:true` 下，`cookies()` 必须在 `<Suspense>` 内，否则 build 报 blocking-prerender；且 TS 不跨模块收窄 `process.env.SESSION_SECRET`，需 `?? ''` 兜底再 throw。
- 验证：build 全绿（页面 Partial Prerender，3 个 API 动态）；curl 全链路通过（注册 200→重复 409→错密码/无用户均 401 同文案→登录 200→首页 Navbar 显昵称→退出 200→首页回未登录）；无 SESSION_SECRET 时 build 报「SESSION_SECRET 环境变量缺失」。
- 注意：验证时向 `data/campus.db` 写了测试账号 `testuser1`（密码 123456），R8 seed 前可忽略。
- 环境：本机 Git Bash 无 `curl`，改用 `/c/Windows/System32/curl.exe`；3000 端口曾被 R1 残留 node 进程占用（PID 需手动 taskkill）。
