## 修掉 Next 16 的 blocking-prerender-current-time 刷屏
- 现象：`npm start` 后每个页面请求都打印 `Route "/xxx": Next.js encountered the unstable value new Date() while prerendering`。
- 定位过程：先怀疑首页（`page.tsx` 无 new Date()），加 `await connection()` 后 `/` 好了、`/search`、`/donate`、`/publish` 还在报 → 说明是布局里的 `Navbar` 与各页面各自调 `getCurrentUser()`；真正的时间来源是 `session-token.ts:81` 的 `nowSeconds(date = new Date())`，被 `auth.ts` 的会话存活校验调用。
