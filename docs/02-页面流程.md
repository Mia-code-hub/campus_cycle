# 页面流程与原型说明

## 1. 站点地图

```
/                首页（搜索框 + 分类筛选 + 物品瀑布流）
/login           登录　/signup 注册
/publish         发布页（三步：上传 → AI 辅助 → 确认）
/items/[id]      物品详情（申领 / 私信 / 收藏）
/search?q=       语义搜索结果页（AI 导购语 + 命中列表）
/donate          公益专区（帮扶生优先曝光）
/me              我的（发布 / 收藏 / 申领 / 捐赠台账）
/me/aid          帮扶资格申请
/admin           管理端（帮扶审核 / 违规留痕 / 数据看板 / 报告导出）
```

## 2. 关键用户旅程

### 旅程 A｜毕业生发布（核心 AI 链路）

```
点「发布闲置」
  └─ 步骤1 上传 1 张图片 + 输入一句口语描述
        ↓ 点「AI 帮我完善」
  └─ 步骤2 调 /api/ai/analyze
        ├─ 成功：回填 类别 / 成色 / 标题 / 文案 / 定价区间 / 标签
        └─ 失败：提示「AI 暂不可用」，保留空白手动表单（不阻断）
        ↓ 用户可逐字段手动修改（AI 内容标注「已采纳/已修改」）
  └─ 步骤3 选择流转模式
        ├─ 低价转售 → 确认定价
        └─ 公益捐赠 → 调 /api/ai/analyze 的 donate 分支生成捐赠标签
        ↓ 提交前调 /api/ai/moderate
        ├─ pass=true  → 入库，status=listed，跳转详情页
        └─ pass=false → 阻断，展示违规类别与原因，允许修改后重试
```

### 旅程 B｜新生语义找物

```
搜索框输入「有没有便宜点的高数课本」
  └─ /api/ai/search
        ├─ query → text-embedding-v3 向量化
        ├─ 与 items.embedding 余弦相似度召回 Top-20
        ├─ 业务加权：donate 且未申领 +0.15；帮扶生身份时捐赠物资强制置顶
        └─ 命中结果 + 相似度 → qwen-plus 生成一段导购说明
  └─ 结果页：上方 AI 导购卡片，下方卡片列表（每张卡标「匹配度 92%」）
  └─ 无结果：展示「换个说法」建议 + 全量捐赠区入口
```

### 旅程 C｜捐赠闭环

```
帮扶生提交资格申请 → 管理员审核通过（is_aid_approved=1）
  └─ 进入 /donate：捐赠物资优先展示
  └─ 点「申请领取」→ 生成 application(status=pending)
  └─ 捐赠人「我的申领」中同意 → status=approved → 双方站内信沟通线下交割
  └─ 捐赠人点「已完成交割」→ item.status=completed，写入 donations 台账
        └─ 调 /api/ai/letter 生成电子感谢信 → /letters/[id] 可在线查看
        └─ 看板统计 +1（流转件数、捐赠件数、节约纸张、减碳量、受益人数）
```

## 3. 页面结构（原型说明，供 AI 生成 UI 时对齐）

**首页**：顶部导航（Logo / 搜索框 / 发布按钮 / 头像）→ 公益横幅（本周捐赠 N 件，累计减碳 X kg）→ 筛选栏（类别、成色、模式、价格区间）→ 物品卡片瀑布流。
**物品卡片**：图片 4:3 → 标题（AI 生成）→ 模式徽章（公益捐赠=暖粉 `blush` / 低价转售=浅青 `sky`）→ 价格或「免费」→ 成色 + 类别小标签。整卡包在**一个链接**里（R19 去掉了卡片内那个没有事件的「收藏」假按钮，收藏能力在详情页）。
**发布页**：左侧实时预览卡片，右侧三步表单；AI 生成时字段区显示骨架屏 + 「AI 正在识别…」状态提示（对应评分项「AI 响应状态提示友好」）。
**详情页**：大图 + AI 文案 + 标签 + 定价区间参考条 + 发起人信息 + 申领/私信按钮 + 违规提示位（管理员可见）。
**管理端看板**：4 个指标卡（流转总量 / 捐赠量 / 节约纸张 kg / 受益人数）+ 折线（月度趋势）+ 饼图（类别分布）+ 柱状（转售 vs 捐赠）+ 台账表格 + 「一键生成环保报告」按钮。

## 4. 视觉规范

粉彩色系为主，三层圆角卡片（页面底 → 区块卡 → 内容卡），轻阴影，hover 上浮 2px；圆角 12/16/20px 三级；主色（暖粉，公益）+ 辅色（浅青，转售）+ 强调（淡紫，AI 能力）；图标线性风格统一。移动端单列，桌面端最多 4 列瀑布流。

R19 之后颜色不再写死，全部收敛到 `src/app/globals.css` 的 `@theme` 令牌，组件里只准引用下列名字（设计稿里的色值仅作对应参考，不进代码）：

| 令牌 | 参考值 | 用途 |
|---|---|---|
| `--color-cream` | `#fdf6f0` | 页面底色 |
| `--color-panel` | `#fffdfa` | 卡片面 |
| `--color-raise` | `#fffefc` | 浮起层（弹窗、下拉） |
| `--color-sunken` | `#f8efe6` | 凹陷区（输入框、骨架、hover 底） |
| `--color-line` / `--color-line-strong` | `#ece1d7` / `#ddcfc2` | 分隔线 / 控件边框 |
| `--color-blush` / `-deep` | `#f7b2bd` / `#ef8fa1` | 主色：公益、主按钮、当前页高亮 |
| `--color-sky` / `-deep` | `#a8d8ea` / `#7cbcd4` | 辅色：转售 |
| `--color-lilac` / `-deep` | `#c7ceea` / `#9aa6dd` | 强调：AI 能力、路由进度条、图表第三色 |
| `--color-ink` / `-soft` | `#4a4a55` / `#8b8b96` | 正文 / 说明文字 |
| `--color-ok` / `warn` / `danger` | 各带 `-soft` `-line` `-deep` | 成功 / 提示 / 危险，底色与描边成套使用 |
| `--color-scrim` / `--color-focus` | `#38383f` / `#9aa6dd` | 弹窗遮罩 / 焦点环 |
| `--color-paper` / `--color-paper-line` | `#fffdf7` / `#f0e8d8` | 感谢信信纸 |

圆角与阴影同样是令牌：`--radius-card-sm/md/lg`、`--shadow-soft/lift`。半透明用 `color-mix(in srgb, var(--color-x) 40%, transparent)`，不写 `rgba()`。`tests/design-tokens.test.ts` 会扫描 `src/app`、`src/components`，出现十六进制、`rgb()`、或 Tailwind 默认调色板类名（`text-red-500` 之类）直接判失败。
