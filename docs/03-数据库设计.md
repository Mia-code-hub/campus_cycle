# 数据库设计（SQLite）

## 1. ER 关系

```
users 1───n items
users 1───n favorites n───1 items
users 1───n applications n───1 items        （申领：转售与捐赠共用）
applications 1───0..1 donations 1───1 letters（捐赠闭环）
users 1───n aid_applications
items 1───n messages（站内信挂在物品下）
users 1───n ai_call_logs（AI 调用留痕，ref_item_id 可空）
items 1───1 embedding（向量存 items 表 BLOB 列）
```

### favorites
`user_id INTEGER`、`item_id INTEGER`、`created_at TEXT`；`PRIMARY KEY(user_id, item_id)`。

### applications（申领单，转售与捐赠共用）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | |

| status | TEXT | pending / approved / rejected / completed / cancelled |
| created_at / updated_at | TEXT | |

### donations（捐赠台账）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | |
| application_id | INTEGER | 来源申领单 |
| item_id | INTEGER | |
| donor_id | INTEGER | 捐赠人 |

### letters（电子感谢信）
`id`、`donation_id`、`content TEXT`（AI 生成）、`receiver_anonymous INTEGER`（是否匿名受赠人）、`issued_at`。

### messages（站内信）
`id`、`item_id`、`from_user_id`、`to_user_id`、`content`、`read_flag INTEGER`、`created_at`。索引 `idx_msg_pair(item_id, from_user_id, to_user_id)`。

### aid_applications（帮扶资格申请）
`id`、`user_id`、`reason TEXT`、`proof_note TEXT`（说明材料，Demo 不传真实证件）、`status TEXT`(pending/approved/rejected)、`reviewed_by INTEGER`、`created_at`、`reviewed_at`。

### ai_call_logs（AI 调用留痕 —— 比赛证据链，必须保留）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | |
| feature | TEXT | analyze / search / moderate / letter / report |
| model | TEXT | 如 qwen-vl-max、text-embedding-v3 |
| user_id | INTEGER | 触发人 |
| ref_item_id | INTEGER | 关联物品，可空 |

| latency_ms | INTEGER | 耗时 |

| created_at | TEXT | |

> 该表是省赛提交材料「AI 对话历史导出的 Prompt 历史快照」的直接来源，`GET /api/admin/ai-logs/export` 导出为 JSON/CSV 即可作为附件。

## 3. 状态机

```
items:  listed ──有人申领并同意──> reserved ──线下交割确认──> completed
          │                            └──取消──> listed
          └──审核不通过 / 举报成立──> removed
applications: pending ──同意──> approved ──确认交割──> completed
              ├─ 拒绝 ─> rejected      └─ 任一方取消 ─> cancelled
aid_applications: pending ─> approved / rejected
```

## 4. 环保折算系数（`src/lib/green-factors.ts`）

| 类别 | 单件重量 kg | 说明 |
|---|---|---|
| textbook | 0.35 | 纸张再生产节约约 0.9 kg 标煤 |
| bedding | 2.5 | |
| stationery | 0.15 | |
| appliance | 1.2 | 按电子废弃物减碳 2.1 kg CO₂e/件 |
| daily | 0.4 | |
| clothing | 0.3 | |

减碳量 = Σ(件数 × 重量 × 0.8 kg CO₂e/kg) + 类别专属修正项。系数写死在配置文件并注明「参考值，用于 Demo 估算」，答辩时如实说明口径，不夸大为实测数据。
